## 📌 Sobre o Projeto Este projeto tem como objetivo demonstrar o domínio dos conceitos fundamentais do desenvolvimento web front-end sem o uso de frameworks ou bibliotecas externas. 

### 🚀 Funcionalidades 

- \*\*Estrutura Semântica:\*\* Organização do conteúdo utilizando tags semânticas para melhor acessibilidade e SEO. 

- \*\*Design Responsivo:\*\* Layout adaptável para dispositivos móveis, tablets e desktops construído com CSS3 puro (Flexbox e Media Queries). 

- \*\*Interatividade &amp; Manipulação do DOM:\*\* Dinamismo e tratamento de eventos com JavaScript puro. 

---
